# Pokemon-Project
A simple game where the player chooses a Pokeball to have a starter Pokemon selected for them. The user choose a colour which corresponds to their chosen Pokemon
# How to Run
1. Make sure you have Python 3 installed.
2. Download the file `ProjectPokemon.py`.
3. Open command prompt and run:
   python ProjectPokemon.py

- Simple program structure and output formatting
